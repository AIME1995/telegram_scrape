# 🧠 Telegram Crypto Influencers Scraper

Ce projet a pour objectif d’analyser l’activité des groupes Telegram d’influenceurs dans le domaine des cryptomonnaies. Il permet de collecter, stocker, nettoyer et visualiser les messages publiés dans ces groupes afin d’en extraire des tendances, des signaux ou des comportements récurrents.

---

## 📌 Objectifs

- Scraper automatiquement les messages d’un ou plusieurs groupes Telegram.
- Analyser le contenu textuel des messages (NLP, fréquence des mots, détection de tokens mentionnés, etc.).
- Étudier l’impact ou la récurrence de certains projets cryptos dans les discussions.
- Identifier les influenceurs les plus actifs ou les sujets les plus récurrents.
- Fournir des visualisations interactives pour explorer les données.
